Smart Learning · macOS 早期测试说明

谢谢你愿意帮我试用！这是仅邀请几位信任的朋友体验的早期版本，还不是正式发布版，可能会有错误或不完善的地方。

为什么 Mac 会提示“无法验证开发者”？
这个测试版暂未完成 Apple 的开发者身份签名与应用公证流程，因此 macOS 无法验证开发者，也无法确认它是否含有恶意软件。这条提示不等于已发现病毒，但也不代表应用已经通过安全审核。
请仅在你直接从我这里收到这个版本、确认来源并愿意参与测试时继续；如果来自转发或陌生链接，请先联系我确认。

第一次怎么打开？
1. 如果收到的是压缩包，先解压，再双击 Smart Learning.app。
2. 出现无法验证开发者的提示时，点“完成”或“取消”，不要点“移到废纸篓”。
3. 打开苹果菜单  → 系统设置（System Settings）→ 隐私与安全性（Privacy & Security）。
4. 向下滚到“安全性”，找到 Smart Learning 被阻止的提示，点“仍要打开”（Open Anyway）。
5. 按提示输入 Mac 登录密码或使用 Touch ID，并在确认框中点“打开”（Open）。
之后通常可以直接双击打开。若没看到按钮，请先再次尝试打开 App，再回到设置查看；学校管理的 Mac 可能不允许自行放行，遇到这种情况请联系我。

程序闪退后在哪里找日志？
Smart Learning 遇到未处理错误时，会把崩溃记录保存在：
~/Library/Application Support/Smart Learning/Logs

在 Finder 顶部菜单选择“前往”→“前往文件夹…”，粘贴上面的地址即可打开。反馈崩溃问题时，可以附上最新的 crash-日期时间.log 文件。日志用于记录错误位置，不会主动保存输入框中的密码；发送前仍建议检查其中内容，不要公开上传包含个人信息的日志。

这次想测试什么？
• 可靠性：能否正常启动、连续使用，有没有卡顿、闪退或保存异常。
• 易用性：操作是否清楚，哪些地方难懂或费力。
• 信任感：你是否愿意用它处理学习或学校相关资料？还希望了解哪些数据处理方式？
• 提前发现问题：在邀请更多学校用户或 IT 人员测试之前，先修复明显的 bug。
可以先用虚构或不敏感的示例资料体验，不需要为了测试提供真实的私人或学校敏感资料。

体验后，欢迎直接把反馈发给我：
1. 能顺利打开吗？使用的是哪个 macOS 版本？
2. 试了什么功能？有没有卡住、报错或出现不符合预期的结果？
3. 哪一步最困惑？最希望改进什么？
4. 你愿意用它处理哪些学习资料？什么信息或改进会让你更放心？
遇到 bug 时，尽量附上“操作步骤、预期结果、实际结果”；截图请遮住个人信息。

谢谢你的时间！真实的困惑和问题，比“挺好用”更能帮我把它做好。
